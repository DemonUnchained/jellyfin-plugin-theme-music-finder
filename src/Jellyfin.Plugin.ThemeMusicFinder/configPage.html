Saves themes as theme.mp3 in each series folder, so Jellyfin needs write access to your TV library. The plugin searches the public Plex TV Themes catalog using each series’ TVDB identifier. If Plex has no match, the optional ThemerrDB fallback uses the series’ TMDB identifier and converts its curated YouTube theme to MP3 with Jellyfin’s FFmpeg. An existing theme.mp3 is never overwritten.

Shows with no theme available are retried on this interval.

Runs nightly at 3:00 AM as the Find missing theme music scheduled task, and optionally the moment a series is added. Run it any time from Dashboard → Scheduled Tasks.

For each series:

  1. Skip if a theme.mp3 is already there.
  2. Read its TVDB and TMDB IDs from Jellyfin metadata.
  3. Skip if it failed recently (see the retry interval).
  4. Try Plex by TVDB ID. Only a confirmed miss falls through to ThemerrDB by TMDB ID.
  5. Download, throttled to about one series per second.
  6. Validate it is a real MP3 — a missing theme returns an error page, not a 404.
  7. Write to a temp file, then rename it into place.
  8. Refresh the item, or Jellyfin never notices the file.

A theme that genuinely does not exist is retried on your interval below. Temporary failures — timeouts, server errors — are not recorded, so a bad hour upstream does not stall your whole library.

Files land at <series folder>/theme.mp3. Playback is a client setting: Settings → Playback → “Play theme songs”.
