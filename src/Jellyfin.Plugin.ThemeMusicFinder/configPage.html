Saves themes as theme.mp3 in each series folder, so Jellyfin needs write access to your TV library. The plugin first checks an exact stable-ID source override, then searches the public ThemerrDB catalog using each series’ TMDB identifier, strictly matched library-aware AnimeThemes openings (or a safe first ending when no opening is available), and finally Plex TV Themes by TVDB identifier. Curated source audio is converted to MP3 with Jellyfin’s FFmpeg. An existing theme.mp3 is never overwritten.

Shows with no theme available are retried on this interval.
-18 LUFS is recommended. True peak is limited to -1.5 dBTP.

Runs nightly at 3:00 AM as the Find missing theme music scheduled task, and optionally the moment a series is added. Run it any time from Dashboard → Scheduled Tasks.

For each series:

  1. Skip if a theme.mp3 is already there.
  2. Read its TVDB and TMDB IDs from Jellyfin metadata.
  3. Skip if it failed recently (see the retry interval).
  4. Try an exact stable-ID source override, ThemerrDB by TMDB ID, an exact title/original-title/verified-ID-alias/synonym and year AnimeThemes match, then Plex by TVDB ID.
  5. Download, throttled to about one series per second.
  6. Normalize new downloads to the configured loudness target.
  7. Validate it is a real MP3 — a missing theme returns an error page, not a 404.
  8. Write to a temp file, then rename it into place.
  9. Refresh the item, or Jellyfin never notices the file.

A theme that genuinely does not exist is retried on your interval below. Temporary failures — timeouts, server errors — are not recorded, so a bad hour upstream does not stall your whole library.

Every completed full sweep also writes ThemeMusicFinder.missing-themes.json in Jellyfin’s plugin configuration folder. It lists unresolved series, IDs, paths, and exact reasons so remaining gaps can be corrected or contributed upstream.

The same folder contains ThemeMusicFinder.source-overrides.json. Map an exact tvdb:ID or tmdb:ID to one hand-picked HTTPS YouTube video when public catalogues have no match. Playlists and generic searches are rejected; editing a URL retries only that series.

The same folder contains ThemeMusicFinder.animethemes-overrides.json. Add an exact AnimeThemes title under a stable tvdb:ID or tmdb:ID key for intentional title variants. Exact returned title/synonym and year validation still applies; editing an override retries only that series.

Files land at <series folder>/theme.mp3. Playback is a client setting: Settings → Playback → “Play theme songs”.
